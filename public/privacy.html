Política de Privacidade — Playlist Picker

Última atualização: 26/08/2026

O Playlist Picker é um pequeno app pessoal que permite que os amigos de um anfitrião adicionem músicas a uma playlist compartilhada no YouTube Music. Esta página explica quais dados o app coleta e como eles são usados.

O que coletamos

Quando um amigo entra, ele informa um nome e um telefone. O telefone é usado apenas para identificar visitas repetidas e garantir o limite de 2 músicas por pessoa — ele não é verificado, não é usado para mensagens e não é compartilhado com terceiros.

Quando um amigo seleciona músicas, os IDs dos vídeos do YouTube escolhidos, os títulos, os artistas e as miniaturas são armazenados para que possamos mostrar uma confirmação e evitar envios duplicados.

Como usamos

Esses dados são usados exclusivamente para operar o app: controlar quem já usou suas escolhas e adicionar as músicas selecionadas à playlist do anfitrião no YouTube por meio da YouTube Data API. Não vendemos, alugamos nem compartilhamos esses dados, e não os usamos para publicidade.

YouTube API Services

Este app usa os YouTube API Services. Ao usar este app, você também concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google. O app só solicita o acesso necessário para buscar vídeos e adicioná-los à playlist do próprio anfitrião — ele não acessa os outros dados do Google ou do YouTube do anfitrião.

Armazenamento e retenção de dados

Os dados são armazenados em um banco de dados controlado pelo anfitrião do app. O anfitrião pode apagar esses dados a qualquer momento removendo os registros correspondentes.

Contato

Dúvidas sobre este app ou sobre seus dados podem ser enviadas diretamente ao anfitrião.
